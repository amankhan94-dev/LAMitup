# Prompt

Create a premium, world-class, one-page website for **LAMitup** ([www.lamitup.com](http://www.lamitup.com)).

## IMPORTANT REFERENCES

Take strong inspiration from this website:

**[https://www.founderos.com/](https://www.founderos.com/)**

I do NOT want to copy the design.

I want to replicate:

* the storytelling
* the content hierarchy
* the minimalist layout
* whitespace
* typography
* premium feel
* clean animations
* confidence in messaging
* section transitions
* CTA placement
* overall user experience

The website should feel like Founderos but built specifically for B2B technology companies.

# Brand

Company:
LAMitup

Website:
[www.lamitup.com](http://www.lamitup.com)

Tagline:

**Don't Just Do It. LAM It Up!**

The brand guidelines define the company as modern, trustworthy, dynamic, polished, sharp, contemporary and confident with a light, clean content style and an energetic accent color. 

The homepage should follow the brand palette:

* White (#FFFFFF)
* Electric Lime (#D4FE01)
* Soft Grey (#E3E5E8)
* Black (#000000)
* Deep Midnight (#0B1026)

Use Bricolage Grotesque for headings and Canva Sans (or a close web equivalent like Inter) for body copy to maintain a modern identity. 

The visual language should be bold, futuristic, human-centric, with generous whitespace and subtle animations.
